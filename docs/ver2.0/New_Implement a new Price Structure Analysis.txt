Implement a new Price Structure / Channel Analysis feature using the existing 2 years of daily OHLCV data already used by the RSI scanner. Keep the implementation simple and reuse existing data pipelines and EOD processing. Do not add a new external market data source.

Goal

Detect high-quality rising parallel channels and identify when price is approaching or testing the 3rd lower-rail touch, because this can be a higher-quality bounce location when combined with existing RSI/momentum confirmation.

Backend / Calculation Logic

Use daily OHLCV history.

Calculate ATR(14).
Detect meaningful pivot lows and pivot highs using a simple 5-bar pivot:
Pivot Low: low is lower than the previous 2 and next 2 bars.
Pivot High: high is higher than the previous 2 and next 2 bars.
Detect rising parallel channels using meaningful pivot lows for the lower rail and pivot highs for the upper rail.
Evaluate multiple lookback windows: approximately 3M, 6M, 12M, 24M.
Select the best valid rising channel based on:
at least 2 independent lower-rail touches
reasonable parallel upper/lower rails
meaningful spacing between touches
prior touches produced a real bounce
A touch is valid when price comes within about 0.35 ATR of the projected lower rail.
Do not count multiple consecutive candles at the rail as separate touches.
Require at least 10 trading days between touches
and price should move at least ~1.5 ATR away before a new touch can count.
A previous touch is considered confirmed if price subsequently bounced at least ~1.5 ATR within the next 10–20 trading sessions.

Suggested rules:

CHANNEL_ACTIVE
Valid rising channel, but price is more than 1 ATR above lower rail.
THIRD_TOUCH_APPROACHING
2 prior confirmed lower-rail touches and current price is between ~0.35 ATR and 1 ATR above the projected lower rail.
THIRD_TOUCH_TEST
2 prior confirmed touches and price is within ±0.35 ATR of the projected lower rail.
REVERSAL_DEVELOPING
Third-touch test occurred and existing Momentum Shift becomes Stabilizing, Bull Turn Early, or RSI starts improving.
BOUNCE_CONFIRMED
Third-touch test occurred and existing momentum logic confirms Bull Turn, preferably with EMA9 confirmation and/or bullish close structure.
CHANNEL_BROKEN
Daily close is materially below the lower rail, for example more than ~0.5 ATR below it.
Important

A 3rd touch is not automatically a Buy.

Channel analysis defines location.
Existing RSI / momentum logic defines timing.

Example:

Third Touch + Still Falling → WAIT FOR REVERSAL
Third Touch + Stabilizing → REVERSAL WATCH
Third Touch + Bull Turn → BUY WATCH
Third Touch + Bull Turn + confirmation → ENTRY CANDIDATE
Channel Broken → AVOID or EXIT REVIEW depending on whether it is owned.
Gap Detection

Add simple daily gap detection using existing OHLC data.

Detect:

Gap Up when Today Low > Previous Day High
Gap Down when Today High < Previous Day Low

Track:

nearest open gap above current price
nearest open gap below current price
gap low
gap high
distance to gap %
whether gap has been filled

Do not treat a gap as a guaranteed target.
Label it as Open Gap Above / Open Gap Below.

Final Design Principle

Keep the decision hierarchy:

Fundamentals / Value → What to own
Allocation → How much room exists
Channel / Price Structure → Where price is
RSI / Momentum → Whether direction is turning
Role → How aggressively to act
Action Center → What requires attention now

Prioritize simplicity, reuse existing services, and avoid introducing extra indicators unless required for the channel calculations.
