## Summary

Eight issues were identified, analysed, and resolved across the Portfolio, Allocation, Dashboard, and Config features. Backend and frontend changes were applied.

| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Symptom**       | `earningsDate` column visible but all rows show `—`                                                                                                                                                                                                                                                                                                   |

## Issue 3 — MY PORTFOLIO: Grid role selector changes do not survive a page reload

|                   |                                                                                                                                                                                                                                                                                                                                                                   |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Symptom**       | Inline role selector updates the UI instantly (optimistic update) but after a browser refresh, the old role reappears.                                                                                                                                                                                                                                            |
| **Root cause**    | The `PATCH /api/portfolio/{id}/holding-role` endpoint saved the new role to `PortfolioItems.HoldingRole` in the DB, but the **`PortfolioSnapshots` table** (the cached JSON used on cold load) was never updated. On the next page load, `GET /stocks/quotes/snapshot` returned the stale snapshot and reverted the role.                                         |
| **Resolution**    | Added `PatchHoldingRoleAsync` to `IPortfolioSnapshotService` and `PortfolioSnapshotService`. The method deserialises the snapshot JSON, finds the item by ID, updates `HoldingRole` in-place, and re-saves. The `PortfolioController.UpdateHoldingRole` endpoint now calls `PatchHoldingRoleAsync` after a successful DB update — no Yahoo Finance call required. |
| **Files changed** | `PortfolioSnapshotService.cs`, `PortfolioController.cs`                                                                                                                                                                                                                                                                                                           |

## Issue 4 — ALLOCATION: "Positions" KPI card shows only stock count

|                   |                                                                                                                                                                                                       |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Symptom**       | Allocation page showed 103 positions; Portfolio header showed 135.                                                                                                                                    |

| **Files changed** | `allocation-page.component.html`                                                                                                                                                                      |

## Issue 6 — DASHBOARD: Auto-refresh interval only updates Portfolio, not Dashboard

|                   |                                                                                                                                                                                                                                                                                                                             |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Symptom**       | After the portfolio auto-refreshed (fetching live prices and saving a new `PortfolioSnapshot`), the Dashboard still showed old snapshot data — requiring a manual browser refresh to see updated values.                                                                                                                    |
| **Root cause**    | `DashboardStateService` had **no auto-refresh timer**. It only loaded the `DashboardSnapshot` once on init. The portfolio auto-refresh updated `PortfolioSnapshots` but never signalled the dashboard to rebuild. The Dashboard only updated when the user clicked the **Refresh** button (`POST /api/dashboard/refresh`).  |
| **Resolution**    | After `getAllQuotes()` completes in `PortfolioStateService`'s auto-refresh pipe, `dashboardState.refresh()` is now called. This chains the dashboard rebuild _after_ the fresh portfolio snapshot is saved, guaranteeing temporal ordering. The dashboard now rebuilds on every portfolio auto-refresh cycle automatically. |
| **Files changed** | `portfolio-state.service.ts` (added `DashboardStateService` inject + `dashboardState.refresh()` call)                                                                                                                                                                                                                       |
