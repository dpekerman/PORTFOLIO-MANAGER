## MOMENTUM SHIFT — Uptrend Fix

**File:** `decision-engine.service.ts` (in `calcMomentumShift`)

**Old rule:** `if ((ema9 > 0 && close > ema9 && rsi >= 50 && rsi <= 65) || (rsi >= 55 && rsi <= 65)) return 'Uptrend';`

**New rule:** Requires ALL of:

- Price > EMA9
- RSI14 between 50–65
- RSI14 > RSI9EMA (signal line)
- MACD histogram improving

**Fallback:** When price > SMA50 and RSI 50–65 but short-term checks fail → `'Neutral / Weakening'` (new state)

**New type:** `'Neutral / Weakening'` added to `MomentumShift` type, CSS class `ms-neutral-weak`, base action `'Stand By'`

**Test:** Stock in uptrend zone but with weak MACD → shows "Neutral / Weakening" instead of "Uptrend".

## TECHNICAL / FINAL ACTION — Overbought Pullback 3-State

**File:** `decision-engine.service.ts`

**New TrendSetup values:** `'Overbought-Weak'`, `'Overbought-Resetting'`, `'Reclaim'`

**Logic:** When RSI is in 55–70 range AND pullback indicators detected (MACD weakening OR price < EMA9 OR EMA10 ≈ EMA20):

- BuyScore ≤ 2 OR price < EMA9 OR CloseLocation < 0.50 → `'Overbought-Weak'`
- BuyScore = 3 (and no breakdown) → `'Overbought-Resetting'`
- BuyScore ≥ 4 (all confirmations) → `'Reclaim'`

**Final Action mapping (Watchlist):**

- `Overbought-Weak` → "Stand By / No Add"
- `Overbought-Resetting` → "Watch / Starter Only"
- `Reclaim` → "Accumulate Starter / Small Starter Only"

**CSS classes:** `ts-ob-weak` (red tint), `ts-ob-resetting` (amber tint), `ts-reclaim` (green)

Added to **all** SCSS files: `watchlist`, `scanner`, `portfolio`, `portfolio-summary-bar`

**Test:** Stock at RSI 58-68 with MACD weakening → shows one of the 3 Overbought Pullback states based on BuyScore and price position vs EMA9.
