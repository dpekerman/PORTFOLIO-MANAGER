What happens automatically, in order:
  1. Windows wakes the machine (or the task fires immediately if already awake) at the Wake / start time above.
  2. The Scheduled Task starts the backend if it isn't already running, then triggers automation.
  3. Automation confirms today is a real trading day — weekends/market holidays are skipped automatically (SkippedNonTradingDay).
  4. It acquires a keep-awake lock so the machine cannot fall back asleep mid-run.
  5. It refreshes live market data once (prices for your portfolio + watchlist symbols).
  6. It watches — without duplicating — the existing RSI/EOD Signal scan, Portfolio Snapshot job, and Value Screener, recording each one's real outcome below as they happen (checked every 60s).
  7. It stops watching at Keep-awake-until (or Max poll minutes after wake, whichever comes first) and releases the keep-awake lock so the machine can sleep again.
