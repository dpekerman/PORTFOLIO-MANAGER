How to use this page

Why is this in Configuration?

The Trading Opportunities page needs two lists that no market-data feed supplies reliably: which companies are in the TSX 60, and which sector ETF each sector is compared against. They are reference settings that change only a few times a year (index rebalances), so they are maintained here by an administrator instead of on the Opportunities page. They are never imported automatically.

TSX 60 constituents

  • These are the Canadian stocks added to the Opportunities universe, next to your Watchlist and holdings.
  • Find: type in the search box, click a column heading to sort, or use Current / Retired / All.
  • Add: press Add constituent. A form opens with the last source details pre-filled.
  • Retire: press the remove_circle_outline icon on a row when a company leaves the index. A confirmation window opens first (Cancel is the default). The row is kept and end-dated today, and a message offers Undo for 10 seconds.
  • Restore: choose Retired, then press the restore icon to put a company back.

Sector benchmarks

  • Each sector is compared with one benchmark ETF to produce the Sector / Theme Heat column and part of the score.
  • Edit: press the edit icon. A form opens with the row's values; press Save changes or Cancel.
  • Add / stop using one: press Add benchmark. To stop using one, edit it and untick Active.
  • Aliases are the sector names your data provider uses for the same sector (for example Technology for Information Technology).

After any change, run Refresh analysis on the Trading Opportunities page (or wait for the scheduled refresh) to see it.
